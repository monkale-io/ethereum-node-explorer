# Changelog

All notable changes to this project will be documented in this file.

- Added Transaction Details/Logs tab with local decoding of well-known ERC-20, ERC-721, and ERC-1155 events (no external network calls)
- Minor improvements in Transaction Details

### Changed
- Updated packages

### Added

### Changed
- Updated packages

## [0.1.1] - 2026-03-24

### Added
- Initial release of the Ethereum Node Explorer.
- Basic Ethereum node connection and RPC exploration features.
